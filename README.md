🎌 AnimeSensei

Intelligent Anime Streaming & AI-Powered Recommendation Platform

⸻

🚀 Overview

AnimeSensei is a modern full-stack anime streaming and discovery platform designed to deliver a highly personalized viewing experience.

It combines anime tracking, streaming, and AI-based recommendations into a single seamless platform, allowing users to explore, watch, and manage anime efficiently.

⸻

✨ Features

👤 User System
	•	Secure authentication (login/signup)
	•	User profiles with avatar and bio
	•	Personalized data per user

📺 Anime Streaming
	•	Episode-based streaming
	•	Video player with controls
	•	Auto-play next episode
	•	Watch progress tracking

📚 Anime Management
	•	Watchlist
	•	Planning list
	•	Completed list
	•	Dropped list
	•	Favorites

⭐ Interaction
	•	Rate anime
	•	Comment system with replies
	•	Like comments
	•	Public user profiles

🔍 Discovery
	•	Advanced search and filtering
	•	Genre-based browsing
	•	Trending & top-rated anime

🤖 AI Recommendation Engine
	•	Personalized suggestions
	•	“Because you watched…” recommendations
	•	Content-based filtering
	•	Collaborative filtering (future scope)
	•	Mood-based recommendations (planned)

⸻
